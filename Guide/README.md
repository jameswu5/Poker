# The Complete Guide to 6-Max No-Limit Hold'em

A comprehensive, intermediate-to-advanced strategy guide for 6-handed No-Limit Texas Hold'em.

**Scope & approach**
- **Game type:** Cash-focused (100bb deep) with a dedicated tournament-adjustments chapter.
- **Philosophy:** Balanced — we teach GTO baselines, then how to deviate exploitatively based on reads and population tendencies.
- **Level:** Intermediate to advanced. Foundations are recapped quickly, then we go deep.
